Every detail is yours to shape

The defaults already look right — a tidy window, your app on the left, Applications on the right, the app's own icon on the disk. When you care about more, each detail has a flag:

window sizeany width and height you like — 660×500 is the default
icon sizefrom small and subtle to 200px showpieces
icon positionsput the app and Applications exactly where your art wants them
background imageyour artwork, cropped, contained or stretched to fit
solid colourjust a hex like 1e1e1e — no image editor needed
retina artwork@2x images stay sharp instead of going soft
volume namewhat the window and the mounted disk call themselves
custom disk iconhand it a PNG and the .icns is built for you
signingyour Developer ID — opt-in, never automatic
checksuma SHA-256 written beside the dmg for release pages
guided wizard-i asks you one friendly question at a time
automation-y asks nothing; --no-window keeps build servers happy

Every one of them is optional — and the README covers each flag in detail.
